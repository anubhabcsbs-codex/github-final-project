# Simple Interest Calculator

## Project Name
**github-final-project**

## Description
A simple calculator that calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

This project is an open-source Bash-based application created to demonstrate basic financial calculations using simple interest.

## Formula

Simple Interest is calculated using the following formula:

**Simple Interest = (P × T × R) / 100**

Where:
- **P** = Principal amount
- **T** = Time period in years
- **R** = Annual rate of interest (percentage)

## Input
The calculator accepts three inputs:

1. Principal amount
2. Time period in years
3. Annual rate of interest

## Output
The calculator displays the calculated simple interest.

## Example

Input:
- Principal = 10000
- Time = 2 years
- Rate = 5%

Output:
- Simple Interest = 1000

## Technologies Used
- Bash Shell Scripting
- Git
- GitHub

## How to Run

1. Clone this repository.
2. Open the terminal in the project directory.
3. Run the script:

```bash
bash simple-interest.sh
```

4. Enter the principal, time period, and annual interest rate when prompted.
