# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Commit your changes with a meaningful commit message.
6. Push your changes to your fork.
7. Open a Pull Request explaining your contribution.

## Reporting Bugs

If you find a bug, please open an issue and provide:
- A clear description of the problem.
- Steps to reproduce the issue.
- Expected and actual results.

## Suggesting Enhancements

Suggestions for new features and improvements are welcome. Please describe your idea clearly through GitHub Issues.

## Code Guidelines

- Write clean and readable code.
- Use meaningful variable names.
- Add comments where necessary.
- Test your changes before submitting a pull request.

## Code of Conduct

All contributors are expected to follow the guidelines described in CODE_OF_CONDUCT.md.

Thank you for helping improve this project!
